      Settings

      Auto-lock

      You're in the demo. Passphrase and erase settings apply to a real vault.

      Change passphrase

      Use at least 12 characters. Several random words are easy to remember and hard to guess. Older backups still open with the passphrase they were made with.

      Erase vault

      Deletes every key stored in this browser. Make a backup first if you may need them.

      Backups

      1. Save a backup

      A copy of your vault, still encrypted with your current passphrase. Keep it somewhere you'll still have if this device is lost, like a USB drive or a personal cloud folder.

      Show the backup text

      2. Check a backup

      Makes sure a saved backup opens and shows what's inside. Your vault isn't changed.

      3. Merge a backup into this vault

      Adds keys from a backup that aren't already here. Nothing is removed. To replace a vault on a new device, use "Restore from an encrypted backup" on the unlock screen instead.

      Why backups matter
      • Clearing browser data deletes the vault. So does uninstalling the browser or resetting the device. A backup is the only way to get your keys back.
      • Private or incognito windows forget everything when they close. Use a normal window for your real vault.
      • Each browser has its own vault. Use a backup to move your keys to another browser or device.
      • A forgotten passphrase can't be reset. Backups use the same passphrase, so they won't help if you forget it. Keep each service's recovery codes separately.
