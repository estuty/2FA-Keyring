Set up two-factor on popular services

How to add Google, GitHub, Microsoft, AWS and Discord accounts to 2FA Keyring, and how authenticator codes differ from push approvals and passkeys.

Checked against each service's official documentation on 16 October 2026. Menus change over time, so each section links to the source.

Codes, push approvals and passkeys

Services offer several kinds of second step. 2FA Keyring handles only the first:

MethodWhat you doWorks with 2FA Keyring?
Authenticator app codes (TOTP)Type a 6 to 8 digit code that changes every 30 seconds or soYes
Push approvalTap "Approve" or match a number in the company's own appNo, it needs that company's app
Passkeys and security keysConfirm with your fingerprint, face, PIN or a USB/NFC keyNo, these are stored by your device, password manager or key
Text message or email codesType a code sent to youNo, these arrive by message

Passkeys and security keys resist phishing better than any code. Where a service offers them, they're a good choice alongside or instead of codes.

The general pattern

  1. In the service's security settings, choose two-factor or two-step verification, then the authenticator app option. If you're offered the company's own app, look for an option to use a different authenticator app.
  2. When the QR code appears, look for a link to show the key as text, often called "can't scan it?", "setup key" or "show secret key". Copy it into 2FA Keyring's Setup key field. You can also save a picture of the QR code and choose it in the Links or QR images tab.
  3. Enter the code 2FA Keyring shows back into the service to confirm.
  4. Save the recovery codes the service offers, then make a fresh backup of your vault.

Google

  • Google's authenticator option works with 2-Step Verification, so turn that on first.
  • In your Google Account's 2-Step Verification settings, choose Set up authenticator (on some devices, Get Started) and follow the steps.
  • Google's help page doesn't describe a text key. If you can't get one, save a picture of the QR code and choose it in 2FA Keyring's Links or QR images tab.
  • Google notes the new option can take up to 7 days to appear at sign-in.

Source: Google Account Help: Get verification codes with Google Authenticator

GitHub

  1. Click your profile picture, then Settings. In the Access section of the sidebar, choose Password and authentication.
  2. Under Two-factor authentication, click Enable two-factor authentication.
  3. Under Scan the QR code, click setup key to show the key as text, and paste it into 2FA Keyring.
  4. Enter the code 2FA Keyring shows under Verify the code from the app.
  5. Under Save your recovery codes, click Download, then I have saved my recovery codes.

GitHub then runs a 28-day check-up: sign in with a code from 2FA Keyring within that time to confirm everything works. GitHub also recommends adding a security key as a backup.

Source: GitHub Docs: Configuring two-factor authentication

Microsoft

For a personal Microsoft account, two-step verification is turned on from Advanced security options, under Additional security → Two-step verification. Microsoft's help page describes its own Microsoft Authenticator app and security codes sent by email or phone. It doesn't describe adding another authenticator app.

  • If Microsoft offers you a QR code or secret key for "a different authenticator app", 2FA Keyring can use it like any other service.
  • If you're only offered Microsoft Authenticator's sign-in approvals, those are push approvals and can't be used here.
  • Microsoft recommends keeping three pieces of security info on your account. Losing access to your sign-in methods can mean waiting 30 days to get back in.

Source: Microsoft Support: How to use two-step verification with your Microsoft account

AWS

  1. In the IAM console, choose Users, then the user's name, then the Security Credentials tab.
  2. Under Multi-factor authentication (MFA), choose Assign MFA device. Type a device name, choose Authenticator app, then Next.
  3. Choose Show secret key and paste it into 2FA Keyring, or choose Show QR code and save a picture of it.
  4. Type the current code into MFA code 1. Wait for 2FA Keyring to show the next code (up to 30 seconds), type it into MFA code 2, and choose Add MFA straight away.

Each user, including the root user, can register up to eight MFA devices, and AWS recommends more than one. The root user follows a separate procedure, linked from the same page.

Source: AWS IAM User Guide: Assign a virtual MFA device · Root user

Discord

  • Discord supports authenticator apps: you can scan a QR code or enter the secret manually, and the app makes a new code every 30 seconds. Discord's step-by-step enrollment instructions are in its separate article, "Using an Authenticator App on Discord".
  • Save your backup codes after turning it on. To see them later, open the gear icon at the bottom left, go to User Settings → My Account, and select View Backup Codes.

Source: Discord Support: Setting up Multi-Factor Authentication
